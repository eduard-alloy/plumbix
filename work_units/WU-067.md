# WU-067: A removed repository answers as a tombstone

**Status**: ✅ Complete (2026-11-04) · **Features**: F-001, F-010 · **Estimate**: short · **Kai**: ME3X0F (workstream F8QK66, milestone M3 AE14T5) · **Follows**: WU-065 · **Source**: Chart-AI's second-day follow-up, ask 5 (A45)

## Goal

Chart-AI names the repository behind every event's `repo_id` in Plumbix's words, the registration's `url`, read from `GET /repos`. A stream that starts after a removal (a fresh install, a cursor past `repo.removed`, a watch whose id was removed before it connected) finds the id nowhere: the list skips removed registrations (WU-065) and there was no `GET /repos/{id}` at all (only `delete` existed under that path), so the lookup was a 404 by construction. Chart-AI then records those events as `repository:unknown <id>`, poorer than Plumbix's own record, which still holds the row with `removed_at` and `removed_by` (migration 0021).

## Design

- **`GET /api/v1/repos/{id}`** (new): `200` with the `Repo` object the list returns, for a live registration. For a removed one, `410 Gone` with a `RepoTombstone`: `{id, host, url, removed: true, removed_at, removed_by}`, the `by` as recorded by `DELETE /repos/{id}`. An id that never existed stays `404`. A tombstone is not a repository a client may act on, so it is not a `200` with a marker.
- **`GET /api/v1/repos?removed=true`**: the removed registrations as tombstones (`RepoTombstoneList`), for a catch-up reader; the plain list keeps hiding them.
- **Store**: `GetRepoTombstone(ctx, id)` and `ListRemovedRepos(ctx)` read removed rows only; `GetRepo` and `ListRepos` keep skipping them, so nothing else in the server starts seeing a retired repository (settings, deletion, the engine and the poller still refuse it).
- **CLI**: `plumbix repo show <id>` prints the registration, or the tombstone, exit 0 either way (the fact was found); an unknown id is an error. `plumbix repo list --removed` lists the tombstones.
- **MCP, web**: unchanged; the session tools and the cards name repositories through the plain list.
- **Not in this unit**: resurrecting a removed registration (register the remote again, WU-065); tombstones in the plain list; the browser (the card left with the removal).

## Steps

4. Docs: OpenAPI, README, ARCHITECTURE, CONSTRAINTS (A45), DISCOVERY Q23, PROJECT (WU-067 to WU-070), CONTEXT_LOG; tell Chart-AI the shape is live.
