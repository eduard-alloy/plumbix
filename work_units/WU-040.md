# WU-040: Repositories as two-line cards

**Status**: ✅ Complete (2026-10-19) · **Features**: F-004 · **Estimate**: small · **Kai**: 363ZQW · **Decision**: A35

## Goal

The Repositories page was an eight-column table that squeezed long URLs. The owner asked for a two-row cell per repository so the information reads at ease, ahead of an import flow on the same page (WU-041, WU-042).

## Design

One card per repository, a list item named `Repository <name>`. Top line: name, host badge, change count, merge strategy, and the Token and Guidance buttons on the right. Bottom line: the full URL (ellipsis only when the window is narrower than it), protected branches, and the token state (host token, own token, or for plain git "uses your SSH keys"). The guidance and token editors open under the card as before.
