# WU-064: Merge strategy settable after registration

**Status**: ⚪ Planned (2026-10-29) · **Features**: F-001, F-010 · **Kai**: BEQRCJ · **Source**: Chart-AI's first-day follow-up, ask 3

`merge_strategy` is fixed at `repo add`. It is the strategy of Plumbix's own merges, and with squash GitHub does not recognise a pull request Plumbix lands as merged, so `merger: plumbix` is unusable on a pull-request repository registered with the default. Add `merge_strategy` to `PUT /repos/{id}/settings`, `plumbix repo set --merge-strategy`, and the card's GitHub panel, under the registration rules (squash, merge, rebase).
