# WU-026: Reviewer presence, a no-reviewer alert, and `plumbix review install`

**Status**: ✅ Complete (2026-10-18) · **Features**: F-003, F-004 · **Estimate**: 1 session · **Kai**: 8WZQWN

## Goal

Plumbix's own AI review depends on a reviewer loop running somewhere (WU-023). When none is, a person should know within minutes, not after the step's timeout; and the loop should survive reboots and server restarts without anyone remembering to start it. The server observes; the operating system keeps the loop alive; the server never spawns it (A27).

## Design

**Presence.** Every poll of `GET /api/v1/reviews/next` is a heartbeat. The engine keeps, in memory, each reviewer's name, repository filter and last poll time; `GET /api/v1/reviewers` lists them, most recent first. Presence is not persisted: a restarted server has heard from nobody until the next poll, which is the truth.

**Alert.** When a run publishes an external review and no reviewer has polled in the last two minutes (`presenceWindow`), the engine raises an alert of kind `no_reviewer` with key `<repo_id>`, one per repository, through the alert store, and writes to the step log that `plumbix review --watch` has to run somewhere. The alert resolves when any reviewer whose filter covers the repository polls. A review that stays pending is checked at every poll of the waiting step, so a loop that dies mid-wait raises the alert too.

**Web.** Settings gains "External reviewers": the presence list, or "none connected" with the install command. The alerts page names the new kind and says what to do.

**CLI.** `plumbix review install [--reviewer <name>] [--repo <id>]` writes a launchd agent on macOS (`~/Library/LaunchAgents/com.plumbix.review.plist`: `RunAtLoad`, `KeepAlive`, stdout and stderr to `~/.plumbix/review.log`, the current executable and flags) and loads it with `launchctl bootstrap gui/<uid>`; on Linux a systemd user unit (`~/.config/systemd/user/plumbix-review.service`, `Restart=always`) enabled with `systemctl --user enable --now`. `plumbix review uninstall` unloads and removes it; `plumbix review status` says whether the agent is installed and running and which reviewers the server has seen. The install logic lives in `internal/reviewer` with the home directory and the command runner injectable, so tests write into a temporary home and talk to a fake `launchctl`.
