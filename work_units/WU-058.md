# WU-058: Changes list rows on two lines

**Status**: ✅ Complete (2026-10-28) · **Features**: F-004 · **Estimate**: short · **Kai**: FZMGC6 (workstream F8QK66, milestone M2 PZTRDV) · **Follows**: WU-057

## Goal

The owner asked for the changes list row to read on two lines: the first with the state, the origin tag, the title, who submitted it and when it last moved; the second with the repository, the branches, the verdict and the iteration.

## Design

- Each row stays one `<button>` (the whole row clickable and focusable, keyboard navigation unchanged) holding two `.line` grids. `.line-1`: `116px 64px minmax(120px,1fr) 120px 44px` for state, origin, title, by, moved. `.line-2`: `minmax(90px,0.5fr) minmax(110px,1fr) minmax(170px,0.8fr) 28px`, indented 224px so it starts under the title, for repository, branches, verdict and iteration (the verdict gets the room the first line no longer needs). Row height goes from 36px to two 22px lines with 6px above and below.
- The column header and the skeleton rows mirror the two lines; the design page's sample row too. The `.row-grid` rule is gone.
- `web/design/README.md` describes the new row.
