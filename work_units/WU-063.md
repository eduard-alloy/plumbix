# WU-063: Auto-merge recorded as the system's act

**Status**: ⚪ Planned (2026-10-29) · **Features**: F-010 · **Kai**: QDXWCV · **Source**: Chart-AI's first-day follow-up, ask 2

GitHub attributes an auto-merge to the account that requested it, so `change.merged` carries `merged_by: <requester>` and Chart-AI records a human act where the gate decided. Add `auto_merge: true` to the merge record and the `changeMerged` payload (additive) when GitHub merged on the requester's behalf, detected from the pull request's `auto_merge` object while open (poller and the webhook's `auto_merge_enabled` / `auto_merge_disabled` actions) and confirmed from the issue timeline's `auto_merge_enabled` event at merge time; keep `merged_by` as the requester. The change page says "merged by auto-merge, requested by <login>".
