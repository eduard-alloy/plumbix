# WU-037: The editor can make a validator external

**Status**: ✅ Complete (2026-10-19) · **Features**: F-004 · **Estimate**: half a session · **Kai**: WMEPT1

## Goal

The owner added a validator step in the pipeline editor to answer it from the review loop and could not make it look like `ai-review`: the editor reads and keeps `external: true` (WU-023 fix) but nothing in it turns the flag on, so every new validator is a container step with an image. After this unit a validator has an External switch, and the reviewer list offers only the profiles that can answer the kind of step selected.

## Design

**Model.** `toggleExternal(p, id)` on a validator: on, the step becomes external and loses its commands, env, secrets, retries and effort (the writer already leaves out the image); off, it gets back an image, `plumbix-ai-validator:dev` when it had none. Either way the reviewer is cleared, since a profile of one family cannot answer the other (A29). A plain step refuses the toggle. `diffSummary` names the change (`external` or `runs in the pipeline`).

**Inspector.** Under Validator, an External switch with its meaning: answered outside the pipeline by `plumbix review --watch` with Claude Code, no image or commands. The reviewer select lists Claude Code loop profiles for an external step and the other kinds for a container step; a reviewer the step names that is not in the list stays selectable, marked not defined or of the wrong kind, so the editor never silently changes it.
