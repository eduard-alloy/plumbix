# WU-073: A front page, with the manual moved under docs/

**Status**: ⚪ Planned · **Features**: docs · **Estimate**: one session · **Kai**: QNB7VB (workstream XVACVT, milestone O1 HGFMS1) · **Follows**: WU-072 · **Source**: outside feedback of 2026-11-06, points 2, 3 (quickstart part) and 8; A48

## Goal

A newcomer reads README top to bottom and leaves knowing what Plumbix is, why it exists, how to run it in five minutes, the five concepts, and why it is not GitHub Actions plus a review bot. Everything else is one link away and nothing is lost.

## What is wrong today

- README is 112 lines under 11 headings. "Pause or remove a repository" and "Gate GitHub pull requests" are single paragraphs of 400 to 900 characters mixing the basics with expiry reasons, 409s, tombstones and launcher variables.
- Ten work-unit ids (WU-061 to WU-071) appear in user-facing text before a reader knows what a change is.
- The quickstart at line 37 runs `plumbix submit -f change.json` and never shows the file; the example at line 98 sits under "Plumbix validates itself". The minimal `.plumbix/pipeline.yaml` is only in ARCHITECTURE.md section 4.2.
- There is no docs/ folder and no comparison with the obvious alternative.

## Design

1. **README order**: what it is (two sentences), why it exists (the "Why it exists" bullets from PROJECT.md, lifted), status line (from WU-072), quickstart, concepts, comparison, links, license.
2. **Quickstart** shows, inline and copy-pasteable: the build or download, `plumbix serve`, a bare repository, a minimal `.plumbix/pipeline.yaml` (build and test steps plus the reference validator), the `change.json` from today's line 98, submit, events, merge. Settings in the browser in one line.
3. **Concepts**: change, acceptance criteria (written with the specification, frozen at intake), validator (deterministic and AI, advisory), verdict, human approval (`needs_human`, never an AI alone). One short paragraph each.
4. **Comparison**: one table against "GitHub Actions plus an AI review bot": intent and criteria fixed before the code; verdicts tied to criteria; deterministic plus AI validators; a human gate; free local parallelism; self-hosted.
5. **docs/**: `docs/reviews.md` (AI reviewers, profiles, `review --watch`, the external step, expiry reasons, the claude-code image), `docs/github.md` (the App, check runs, the hold, holding ref, `merger`, auto-merge, bypass alerts), `docs/repositories.md` (register, tokens, pause, remove, tombstones, merge strategy). Moved text is moved verbatim; WU and A ids stay there. `docs/agents.md` holds the MCP section's detail if the README's version is cut.
6. **Self-validation** section stays, shortened to three sentences and a link; its contribution line is WU-074's.
