# WU-069: A session the review loop starts says who launched it

**Status**: ✅ Complete (2026-11-04) · **Features**: F-010, F-011 · **Estimate**: short · **Kai**: 6ZCMDS (workstream F8QK66, milestone M3 AE14T5) · **Follows**: WU-068 · **Source**: Chart-AI's project model draft, P10 (a launcher is a fact the platform can state); the byte-for-byte url rule relayed by plumbix-bb on 2026-11-04

## Goal

Chart-AI matches our review loop's sessions by a worktree path on one machine (`eduard@m4pro:/Users/eduard/.plumbix/review/worktrees/*`), a rule valid for one user and one Mac. Its draft asks the launching platform to state two facts in the session's environment, which its Claude Code hook reads: the repository the worktree is a checkout of, and that Plumbix's review loop started the session rather than a person at a terminal.

## Design

- **Contract** `contracts/launcher.md`: the variables, their stability and their meaning. A session `plumbix review --watch` starts for a brief carries `PLUMBIX_LAUNCHER=review`, `PLUMBIX_REPOSITORY` (the registration's `url` byte for byte as `GET /api/v1/repos` returns it, never normalised: Chart-AI normalises and applies its own aliases), `PLUMBIX_REPO_ID`, `PLUMBIX_CHANGE`, `PLUMBIX_RUN` and `PLUMBIX_REVIEW` (the brief's ids). The AI validator image (`validators/claude-code`) sets what it knows when it starts Claude Code inside its container: `PLUMBIX_LAUNCHER=validator` and `PLUMBIX_CHANGE`; its input carries no run or repository, so those are absent there.
- **Code**: `review.Brief.LauncherEnv()` builds the six pairs from the brief; the reviewer passes them as `claudecode.Options.Env`, which appends them to the inherited environment (a stale value from the loop's own environment is replaced, since `environment` drops names the extras set). The validator passes its two.
- **Not in this unit**: a marker on the loop process itself (the hook runs in the session, not in the loop); reading the marker anywhere in Plumbix; Chart-AI's rule.

## Steps

1. Failing reviewer test: the fake `claude` records its environment; the six variables carry the brief's values. Failing validator test: launcher and change.
2. `Brief.LauncherEnv`, the constants, the two call sites.
3. `contracts/launcher.md`; README, ARCHITECTURE (contracts table, external validator bullet), CONSTRAINTS, PROJECT, CONTEXT_LOG; `make check`.
