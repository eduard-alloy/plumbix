# WU-025: Any model for the AI validator (OpenAI-compatible provider)

**Status**: ✅ Complete (2026-10-18) · **Features**: F-003 · **Estimate**: 1 session · **Kai**: K5XHAD

## Goal

The container AI validator can ask any model that speaks the OpenAI chat format, not only Claude: OpenAI, Gemini through its compatible endpoint, xAI's Grok, Moonshot's Kimi, DeepSeek, Groq, and local servers such as Ollama or vLLM. The operator picks the provider, base URL and model in Settings; the key is a secret the pipeline step names, as today (A25).

## Design

**Provider.** `aivalidator.Config` gains `Provider` (`anthropic`, the default, or `openai`) and `BaseURL`. The Anthropic path is unchanged. The `openai` path posts to `<base>/chat/completions` with the system and user prompts as messages, the model, and `response_format: {type: json_schema}` carrying the verdict schema; a vendor that rejects `json_schema` gets a second request with `json_object`, and one that rejects that gets a plain request. The user prompt ends with the schema and an instruction to answer with one JSON object, since not every vendor enforces the format. Fenced JSON in the answer is unwrapped. The answer goes through `review.ToVerdict` like Claude's, so a weak vendor degrades to a validator error, never to a false approval. Usage comes from the response's `usage` and `model`. No vendor SDK: the format is small and `net/http` keeps the image small.

**Key.** For `openai` the validator reads `PLUMBIX_AI_API_KEY`, then `OPENAI_API_KEY`; the pipeline step lists whichever secret holds the vendor's key. A missing key fails cleanly naming both variables.

**Settings.** `ai_provider` and `ai_base_url` join `ai_model`; validator steps receive them as `PLUMBIX_AI_PROVIDER` and `PLUMBIX_AI_BASE_URL`, the way `PLUMBIX_AI_MODEL` travels. The web Settings page gains a provider choice and, for `openai`, a base URL field with the known vendors' URLs as hints. `OPENAI_API_KEY` joins the known secrets.

**Live tests.** `make live` runs the OpenAI path when `OPENAI_API_KEY` (and optionally `PLUMBIX_AI_BASE_URL`) is set, skipping otherwise.
